# Security Policy

## Supported versions

Keychain is in public beta. Only the latest `0.x` prerelease published under the
`beta` dist-tag receives security fixes. Older prereleases are not patched;
upgrade to the latest beta.

| Version           | Supported |
| ----------------- | --------- |
| latest `0.x` beta | Yes       |
| older prereleases | No        |

## Reporting a vulnerability

Do not open a public issue for security problems. Report privately through
[GitHub security advisories](https://github.com/Mysamyr/keychain/security/advisories/new).

Include the affected package and version, a description of the impact, and
reproduction steps. You will receive an acknowledgement within 5 business days.
Fixes are released as a new prerelease and disclosed in a GitHub advisory once
users can upgrade.
